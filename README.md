# OTUS Architecture Web Project

## Сквозной проект

Тема проекта:

SSR-платформа для контентного сайта с использованием микросервисной архитектуры.

В рамках курса будет разработана архитектура системы, включающая:
- SSR-сервер;
- взаимодействие с внутренними сервисами;
- кэширование;
- CDN;
- отказоустойчивость;
- масштабирование;
- документацию архитектурных решений (ADR).
